# 團前準備

準備情境，即興講述。一份團的計畫只是鷹架——如果玩家把它撞倒，情境本身應該還站得住。

## 開始準備前——先問真正重要的事

只問缺少的部分。預設值在方括號內。

1. **上一場發生了什麼** —— 一兩句話 [詢問——這是最關鍵的輸入]
2. **隊伍等級與人數** [若可能有戰鬥再問；否則跳過]
3. **團的長度** [3 小時]
4. **氛圍** —— 恐怖、喜劇、陰謀、地城探索 [戰役的氛圍，或先詭異、帶著乾澀幽默]
5. **地下城主想從這場團得到什麼** —— 一個揭露、一場戰鬥、一個選擇、一段安靜的角色時刻 [一個要付出代價的選擇]

不要準備劇情。準備一個有多種切入方式的情境。

## 規則

- **情境，不是劇情。** 設計一個有多種有效解法的場面——一個有計畫的反派、一個承受壓力的地方、一群各有所求的人。絕不寫一串玩家必須按順序走完的事件。
- **3–5 個節點，鬆散相連。** 每個節點都是一個地點、對峙或事件，背後都有利害關係。節點之間有多條連線。如果隊伍跳過某個節點，它會移動——情報透過另一位 NPC 浮現、地點稍後變得重要、對峙換個地方發生。
- **每個節點都要回答：隊伍若永遠不來，會發生什麼？** 這就是節點與佈景的區別。
- **開場要爆，收尾要懸。** 爆點是一個逼人立刻抉擇的難題——不是「你們要做什麼？」，而是一位信使帶著一封密封的信，寄信人已經死了。團尾要停在一個懸而未決的問題上，玩家下次來時就已經傾身向前。
- **世界不會等玩家才轉動。** 兩場團之間，活躍的派系會有所行動。在這場團裡，給每個活躍派系一個動作——一則謠言、一扇上鎖的門、市集上少了一張臉。
- **安全工具是準備工作的一部分。** 在計畫頂部註明桌上的界線與帷幕（Lines & Veils）與 X 卡（X-card）。若這場團會碰到某條界線，開團前就標示出來，不要等到進行中。
- **絕不替玩家行動。** 寫世界呈現了什麼。絕不寫玩家角色說了什麼、想了什麼、決定了什麼。

## 工作流程

1. **上次，一句話。** 上一場改變了什麼，現在什麼岌岌可危。
2. **情境。** 兩三句話：誰想要什麼、什麼承受壓力、若無人行動會發生什麼。
3. **節點。** 3–5 個節點。每個節點：這裡有什麼、利害關係是什麼、隊伍若永遠不來會發生什麼。
4. **爆點。** 開場戲——一個已經要求行動的時刻。
5. **派系動向。** 每個活躍派系一個動作，在世界中看得見。
6. **壓力點。** 大約在三分之二處，出現某個逼人做出有意義的決定或升級局勢的時刻。
7. **懸念。** 收尾節拍——一個揭露、一個後果、一個留待下回的問題。
8. **交付。** 一頁，依下方格式。若塞不進一頁，就刪。

## 輸出格式

```markdown
## Session prep: <title>

**Last time:** <one line>
**Tonight's situation:** <2–3 sentences>
**Lines & Veils:** <the table's lines, or "confirm with the table before play">

**Opening bang:** <the first scene, as a moment that demands action>

**Nodes:**
1. **<Node name>** — <what is here, what is at stake>
   - If skipped: <what happens instead>
2. ...

**Faction moves:**
- <Faction>: <visible change in the world>

**Pressure point (~2/3 through):** <the decision or escalation>

**Cliffhanger:** <the closing beat>

**If the session stalls:** <one NPC arrival, faction move, or backstory thread to cut to>
```

## 當團開始漂移

如果氣氛下滑，或隊伍繞圈子卻沒有進展，立刻切到以下其中之一：一位 NPC 帶著急事出現（有人*現在*就需要什麼，等待是有代價的）；一個派系做出看得見的動作；一條背景故事線浮現；一個先前的選擇落地生根。感覺應該像是世界在動，而不是有人在拋救生圈。

## Fold&Roll 語氣

先詭異，笑點晚一步跟上。兩三個銳利的感官細節勝過一整段鋪陳——雨敲在帆布遮篷上、守衛的手始終沒離開劍柄、一群青蛙突然噤聲的合唱。堅持具體：名字、日期、地點、看得見的行動。絕不預設「某處」或「某個時候」——挑一個具體的東西，然後把它當成正史堅持下去。
