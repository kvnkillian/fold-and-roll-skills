# 擲骰

擲骰、顯示骰面，讓結果成立。無論朝哪個方向，都不竄改。

## 擲骰之前——先問清楚重要的事

只問缺少的部分。預設值在方括號內。

1. **擲什麼**——表示法，例如 `2d6+3`、`d20`、`4d6`[要問——沒有安全的預設值]
2. **優勢／劣勢**——針對 d20 檢定[兩者皆無，除非使用者有說]
3. **這次擲骰的目的**——攻擊、檢定、豁免、傷害[若會改變對結果的解讀就問；否則直接擲，並說明這是為什麼而擲]

如果使用者只說「擲骰」，先問一次表示法，然後擲骰。

## 規則

- **顯示骰面，而不只是總數。**永遠先報出每一顆骰子，再報總數：`2d6+3: [4, 2] + 3 = 9`。只有總數、沒有骰面，就不算一次擲骰。
- **能用腳本就用腳本。**從存放庫根目錄執行 `python3 scripts/roll.py <notation>`（Python 3，僅用標準函式庫），並回報它的輸出。如果沒有這個腳本，就誠實地擲骰，並說明這次是沒有用腳本擲的。
- **優勢與劣勢都是擲兩顆 d20。**優勢：擲兩顆 d20，取較高者。劣勢：擲兩顆 d20，取較低者。兩顆骰子都要顯示。絕不要只擲一顆骰子就說是優勢。
- **自然 20 在攻擊中是重擊；自然 1 是致命失手。**重擊後的傷害擲骰，把傷害骰擲兩次（不要把加值加倍）。發生時要說出來——「自然 20，重擊」——然後擲傷害。
- **在骰子落下之前，或落下之後立刻，說出 DC 或目標**——絕不要等玩家已經根據結果、改走另一條路之後才說。
- **絕不竄改擲骰結果。**結果對隊伍不利，或對怪物不利，都成立。失敗的擲骰會改變局勢；它不會讓故事停下來。
- **未經要求，絕不為玩家角色擲骰。**玩家擲自己的骰子。代理為怪物、NPC 與整個世界擲骰——只有在玩家要求時，才為玩家擲骰。

## 表示法

| 表示法 | 意思 |
|---|---|
| `d20` | 一顆 20 面骰 |
| `2d6+3` | 兩顆 6 面骰，加 3 |
| `4d6 drop lowest 1` | 四顆 6 面骰，捨棄最低的一顆（屬性值） |
| `d20 advantage` | 兩顆 d20，取較高者 |
| `d20 disadvantage` | 兩顆 d20，取較低者 |
| `8d6` | 八顆 6 面骰（例如火球術） |
| `1d4+1` | 一顆 4 面骰，加 1 |

加值只加一次，在骰完之後——絕不要每顆骰子各加一次，除非規則有這樣說。

## 輸出格式

```markdown
**Roll:** <what it was for>
**Dice:** <notation>: [<each die>] <+/- modifier> = <total>
**Result:** <what it means — hit / miss, save / fail, damage dealt>
```

優勢／劣勢時：

```markdown
**Roll:** <what it was for> — advantage
**Dice:** d20: [14, 7] → take 14, + 5 = 19
**Result:** <what it means>
```

## 團體擲骰

當好幾個生物擲同一樣東西——例如一群哥布林進行豁免——每個生物各擲一次，每個結果各寫一行。除非使用者要求這樣做，否則不要只擲一次就套用到整群生物身上。

## Fold&Roll 語氣

骰子是唯一語氣保持平實的地方。擲骰本身不要華麗修飾——戲劇性在結果裡，不在回報裡。一行寫骰子，一行寫它的意思，然後回到遊戲。
