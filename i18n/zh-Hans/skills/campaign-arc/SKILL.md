# 战役弧线

一条战役弧线有一个主题和一个收尾，中间有六个节拍。这些节拍是后果，而非事件——每一个节拍都由“它落地之后什么必须*不同*”来定义，而不是由“它如何落地”来定义。

## 动手之前——先问清关键信息

只问缺失的信息。方括号内为默认值。

1. **前提**——一句话：这场战役是关于什么的？ [必须问]
2. **队伍等级范围** [1–10，或用户给出的范围]
3. **预计长度**——大约多少场团 [10–15]
4. **基调** [先诡异、带冷幽默]
5. **地下城主已经知道的事**——一个反派、一个地点、一个派系、一个队伍已经了解的事实 [没有]

## 规则

- **节拍是后果，而非事件。** 事件是一件具体发生的事（“公会会长签署了法令”）。后果是世界的一种改变后的状态（“队伍失去了公会内部唯一能为他们担保的盟友”）。十几个场景都能达成一个后果；一个被提前破坏的事件就能毁掉一个事件形态的节拍。把每个节拍都写成“之前 / 之后”。
- **主题与收尾先行。** 主题：一句话——这个故事最终*关于*什么，不是威胁本身，而是它的含义。收尾：一个已承诺的终点形态——如果队伍成功了，情感上的真相是什么？承诺形态本身，具体的事件保持开放。
- **中点转折不可或缺。** 没有它，第二幕会无限期地漂移。如果到了预计团数大约一半时它还没有落地，就加大世界压力，直到它落地。
- **“一无所有”要靠挣得，而不是惩罚。** 它来自世界的逻辑，而不是随意的坏运气。队伍应该能感觉到它正在逼近，却无力阻止。
- **每个节拍之前先施加世界压力。** 每个节拍都内置一个派系或 NPC 的行动，为它创造条件，让节拍感觉像是必然发生，而不是凭空掉下来。绝不要冷冰冰地甩出一个节拍。
- **节拍之前先做铺垫。** 先跑一场铺垫戏，自然地收窄选择空间——两三条看似可行的路，最终都自然地汇聚到这个节拍上，让它感觉是挣得的，而不是强塞的。
- **修订，而不是放弃。** 当玩家的选择让故事转向时，按新的方向重写未完成的节拍，并记录这次修订。被提前破坏是修订的触发条件，而不是跳过节拍的理由：付出代价、产生次级后果，或推迟发生——绝不要强行推进那个已经死掉的事件。
- **只用 SRD，除非用户另有要求。** 有名字的怪物、法术与物品均出自 SRD 5.1 / 5.2.1。自创内容会标明为自创内容。
- **绝不替玩家一方行动。** 弧线是世界的计划。玩家的选择会让它弯曲。

## 六个节拍

| 幕 | 节拍 | 含义 |
|---|---|---|
| 1 | **1a——导火索** | 威胁对队伍而言变得与个人相关。 |
| 1 | **1b——复杂化** | 问题比最初看起来更大或更古怪。 |
| 2 | **2a——中点转折** | 队伍*以为*自己在做的事，让位于他们*实际*在做的事。 |
| 2 | **2b——一无所有** | 一次真正的挫败——有东西失败了、失去了，或在故事的重压下崩塌了。 |
| 3 | **3a——最终对峙** | 战役走向取决于它的决定性时刻。 |
| 3 | **3b——收尾** | 世界与角色在之后有什么不同。 |

## 工作流程

1. **主题与收尾。** 各一句话。如果写不出来，说明前提还没准备好——再多问一个问题，不要注水。
2. **反派与世界压力。** 反派的目标、他们“队伍什么都不做时会发生什么”的计划，以及在节拍之间持续施压的派系或力量。
3. **六个节拍，写成“之前 / 之后”。** 每个节拍：之前的世界、之后的世界、为它铺垫的压力，以及让它显得理所当然的铺垫。
4. **节点。** 3–5 个弧线可以经过的地点、对峙或事件，松散相连，每个都写明如果队伍永远不来会发生什么。
5. **修订日志。** 结尾附一张简表：节拍、改了什么、为什么。当玩家提前破坏一个节拍时，地下城主更新它。这张日志就是弧线还活着的证明。
6. **交付。** 按下面的格式。

## 当一条弧线完成时

一条弧线的收尾，就是下一条弧线的现状。新的弧线必须有意识地与众不同——是从改变后的世界里长出的新篇章，而不是同一场冲突的延续。或者完全不设弧线：沙盒式战役是正当的选择，弧线追踪只是关掉了而已。

## Fold&Roll 语气

先诡异，后幽默。弧线的主题应该能用一句平实的话说清楚，恐怖应该来自世界*做了*什么，而不是对血腥的描写。要敢于具体：一个有名有姓的反派、一个有名有姓的计划、一座有名有姓的城市、一个队伍看得见的代价。
