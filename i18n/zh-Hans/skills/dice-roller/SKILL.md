# 掷骰器

掷出骰子，亮出骰子，让结果成立。无论对哪一方有利，都不作弊。

## 掷骰之前——先问清关键信息

只问缺失的信息。方括号内为默认值。

1. **掷什么**——记法，例如 `2d6+3`、`d20`、`4d6` [请用户说明——没有安全的默认值]
2. **优势 / 劣势**——针对 d20 检定 [都没有，除非用户说明]
3. **这次掷骰是为什么**——攻击、检定、豁免、伤害 [如果会影响对结果的解读就问；否则直接掷，并说明掷的是什么]

如果用户只说“掷骰”，先问一次记法，然后掷骰。

## 规则

- **亮出骰子，不只报总数。** 永远先报每一颗骰子，再报总数：`2d6+3: [4, 2] + 3 = 9`。没有骰面的总数不是一次掷骰。
- **能用脚本就用脚本。** 从仓库根目录运行 `python3 scripts/roll.py <notation>`（Python 3，仅标准库），并报告它的输出。如果脚本不可用，就诚实地掷骰，并说明这次没有用脚本。
- **优势与劣势都是两颗 d20。** 优势：掷两颗 d20，取较高者。劣势：掷两颗 d20，取较低者。两颗骰子都要亮出来。绝不要只掷一颗骰子就称之为优势。
- **攻击中天然 20 即重击；天然 1 即大失败。** 重击后的伤害掷骰，把伤害骰掷两次（不要把加值翻倍）。发生时要说出来——“天然 20，重击”——然后掷伤害。
- **在骰子落下之前说明难度等级或目标，至迟在落下后立刻说明**——绝不能等玩家已经根据结果定下另一个计划之后再说。
- **绝不作弊。** 结果对队伍不利也好，对怪物不利也罢，结果都成立。一次失败的掷骰改变的是局势，而不是让故事停下来。
- **未经要求，绝不替玩家角色掷骰。** 玩家掷自己的骰子。智能体为怪物、NPC 与世界掷骰——只有玩家要求时，才替玩家掷骰。

## 记法

| 记法 | 含义 |
|---|---|
| `d20` | 一颗 20 面骰 |
| `2d6+3` | 两颗 6 面骰，加 3 |
| `4d6 drop lowest 1` | 四颗 6 面骰，去掉最低的一颗（属性值） |
| `d20 advantage` | 两颗 d20，取较高者 |
| `d20 disadvantage` | 两颗 d20，取较低者 |
| `8d6` | 八颗 6 面骰（例如一发火球术） |
| `1d4+1` | 一颗 4 面骰，加 1 |

加值只加一次，在骰子之后——绝不每颗骰子各加一次，除非规则另有说明。

## 输出格式

```markdown
**Roll:** <what it was for>
**Dice:** <notation>: [<each die>] <+/- modifier> = <total>
**Result:** <what it means — hit / miss, save / fail, damage dealt>
```

优势 / 劣势时：

```markdown
**Roll:** <what it was for> — advantage
**Dice:** d20: [14, 7] → take 14, + 5 = 19
**Result:** <what it means>
```

## 团体掷骰

当多个生物掷同一个东西——例如一群哥布林进行豁免——每个生物掷一次，各自的结果各占一行。除非用户要求，否则不要只掷一次就套用到整个团体。

## Fold&Roll 语气

骰子是唯一保持平实的地方。掷骰本身不加花哨——戏剧性在结果里，不在报数里。一行写骰子，一行写它意味着什么，然后回到游戏。
