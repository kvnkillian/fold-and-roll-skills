# ダイス・ローラー

ダイスを振り、ダイスを見せ、結果をそのまま受け入れる。どちらの方向にもごまかしはなし。

## 振る前に — 必要なことだけ尋ねる

不足していることだけを尋ねる。括弧内はデフォルト。

1. **何を振るか** — 表記、例：`2d6+3`、`d20`、`4d6` [尋ねる — 安全なデフォルトなし]
2. **有利／不利** — d20判定の場合 [ユーザーから指示がない限り、どちらでもない]
3. **何のためのロールか** — 攻撃、判定、セーヴ、ダメージ [結果の読み方が変わる場合は尋ねる。そうでなければ振って、何のためだったか伝える]

ユーザーが単に「振って」と言っただけなら、表記を一度だけ尋ねてから振る。

## ルール

- **ダイスを見せる、合計だけではない。** 常に各ダイスを示してから合計を出す：`2d6+3: [4, 2] + 3 = 9`。ダイスのない合計はロールではない。
- **使えるときはスクリプトを使う。** リポジトリのルートから `python3 scripts/roll.py <notation>` を実行し（Python 3、標準ライブラリのみ）、その出力を報告する。スクリプトが使えない場合は正直に振り、スクリプトなしで振ったと言う。
- **有利と不利は2個のd20。** 有利：d20を2個振り、高い方を採用する。不利：d20を2個振り、低い方を採用する。両方のダイスを見せる。1個だけ振って有利と呼んではいけない。
- **ナチュラル20は攻撃におけるクリティカル・ヒット、ナチュラル1はクリティカル・ミス。** クリティカルの後のダメージ・ロールでは、ダメージ・ダイスを2回振る（修正値は2倍にしない）。起きたときはそう言う — 「ナチュラル20、クリティカル・ヒット」 — それからダメージを振る。
- **DC（難易度）または目標値は、ダイスが着地する前か、直後に示す** — プレイヤーが結果をもとに別の計画にすでに踏み切った後では決して示さない。
- **ロールをごまかしてはいけない。** 結果がパーティにとって悪くても、モンスターにとって悪くても、そのまま受け入れる。失敗したロールは状況を変える。物語を止めるのではない。
- **頼まれずにプレイヤー・キャラクターの代わりに振ってはいけない。** プレイヤーは自分のダイスを自分で振る。エージェントはモンスター、NPC、そして世界のために振る — プレイヤーのためには、プレイヤーから頼まれたときにだけ振る。

## 表記

| 表記 | 意味 |
|---|---|
| `d20` | 20面ダイス1個 |
| `2d6+3` | 6面ダイス2個、+3 |
| `4d6 drop lowest 1` | 6面ダイス4個、最も低い1個を除外（能力値） |
| `d20 advantage` | d20を2個振り、高い方を採用 |
| `d20 disadvantage` | d20を2個振り、低い方を採用 |
| `8d6` | 6面ダイス8個（たとえばファイアボール） |
| `1d4+1` | 4面ダイス1個、+1 |

修正値はダイスの後に1回だけ加える — ルールがそう定めている場合を除き、ダイスごとには加えない。

## 出力形式

```markdown
**Roll:** <what it was for>
**Dice:** <notation>: [<each die>] <+/- modifier> = <total>
**Result:** <what it means — hit / miss, save / fail, damage dealt>
```

有利／不利の場合：

```markdown
**Roll:** <what it was for> — advantage
**Dice:** d20: [14, 7] → take 14, + 5 = 19
**Result:** <what it means>
```

## グループ・ロール

複数のクリーチャーが同じものを振る場合 — たとえばゴブリンの集団がセーヴを行う場合 — クリーチャーごとに1回ずつ振り、各結果を1行ずつ並べる。ユーザーがそう頼んだ場合を除き、1回だけ振って集団全体に適用してはいけない。

## Fold&Roll の文体

ダイスは、文体が素朴なままの唯一の場所。ロール自体に飾りはいらない — ドラマは結果にあり、報告にはない。ダイスを1行、それが何を意味するかを1行、それからゲームに戻る。
