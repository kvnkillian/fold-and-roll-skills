# Fold&Roll DM スキル

Fold&Roll の開発チームが贈る、ダンジョンズ＆ドラゴンズを運営するための無料 AI エージェントスキル集。

Claude Code、Codex、Cursor、あるいは Agent Skills オープンスタンダードを読むあらゆるエージェントにインストールすれば、エージェントは感覚頼みの D&D アドバイスをやめ、DM のように準備を始めます。プロットではなくシチュエーションを。出来事ではなく結果を。不気味さを先に、笑いを一拍遅れて。

**全員がテーブルに。**

## スキル一覧

| スキル | 内容 |
|---|---|
| `encounter-builder` | パーティのレベル、人数、難易度から、バランスの取れた印象的な 5e エンカウンターを作成。地形、戦術、そしてひねり付き。 |
| `npc-generator` | 癖と望みと秘密を持った NPC。声、フック、そしてパーティが無視したらどうなるかまで。 |
| `session-prep` | 1 ページのセッションプレップ。シチュエーション、3〜5 個のノード、シーン・バング、派閥の動き、そして締めのクリフハンガー。 |
| `one-shot-builder` | 3〜4 時間のワンショットをまるごと 1 本。フック、三幕構成、エンカウンター、NPC、そして決着。 |
| `solo-adventure` | 1 人のプレイヤーとエージェント DM によるソロアドベンチャー。選択、結果、そして本物の結末。 |
| `campaign-arc` | 三幕六ビートのキャンペーン・アーク。何が起きるかではなく、何が変わるかで定義する。 |
| `dice-roller` | どんなダイスでも振る — 有利、不利、クリティカル、ダメージ、グループ・ロール — 合計だけでなくダイスそのものを見せる。 |

## インストール

### Claude Code

```sh
claude plugin install fold-and-roll-skills@kvnkillian
```

または、スキルを個人のスキルフォルダにコピーします。

```sh
git clone https://github.com/kvnkillian/fold-and-roll-skills.git
cp -r fold-and-roll-skills/skills/* ~/.claude/skills/
```

### Codex / Cursor / Copilot

```sh
npx skills@latest add kvnkillian/fold-and-roll-skills
```

または、プロジェクト内の `.agents/skills/`、個人利用なら `~/.agents/skills/` にスキルをコピーします。

### その他のエージェント

`skills/<name>/` フォルダを、エージェントがスキルを読み込む場所にコピーしてください。各スキルは 1 つの `SKILL.md` ファイルだけです。ビルド手順も依存関係もありません。`scripts/roll.py` のダイスヘルパーには Python 3 のみが必要です。

## 使い方

エージェントに普段の言葉で頼んでください。各スキルの説明が、いつ発動すべきかをエージェントに伝えます。

- 「レベル 5 のキャラクター 4 人分のエンカウンターを作って。難易度はハード、水没した神殿で」
- 「NPC を 1 人ちょうだい。知りすぎている鍛冶屋」
- 「今夜のセッションを準備して。前回パーティはギルドとの橋を焼き払った」
- 「幽霊灯台のワンショットを書いて」
- 「レベル 3 のローグでソロアドベンチャーを回して」
- 「自分の名前を忘れた街をめぐるキャンペーン・アークを計画して」

エージェントは本当に必要な詳細だけを尋ねます。パーティのレベルと人数、トーン、セッションの長さなどです。そのうえで、すぐに使える完成品を届けます。

## Fold&Roll のやり方

これらのスキルは、Fold&Roll が基づいているのと同じルールに従います。

- **プロットではなくシチュエーションを準備する。** シチュエーションはプレイヤーとの接触に耐えます。プロットは、プレイヤーが予想外のことをした瞬間に壊れます。
- **プレイヤーは共著者。** プレイヤー・キャラクターのセリフ、思考、決断を代弁してはいけません。選択は常にプレイヤーのものです。
- **不気味さを先に、笑いを一拍遅れて。** 不穏なものの隣に置かれたジョーク、乾いた神経質なウィットを添えたホラー。グロテスクな描写は決して目的にしません。
- **SRD のみ。別途指示がない限り。** モンスター、呪文、アイテムは SRD 5.1 / 5.2.1 から。ホームブルーはホームブルーと明記し、エージェントは作る前に尋ねます。
- **安全第一。** セッション・ゼロ、Lines & Veils（ラインズ＆ヴェイルズ）、Xカード（X-card）は準備の一部であり、後付けではありません。
- **全員がテーブルに。** コンテンツはすべてのプレイヤーが使えるものに。明確な言葉、視覚だけの情報なし、目や耳がなければ通じないジョークなし。

- **Android ベータ:** https://play.google.com/apps/testing/com.kevin.rpgcompanion
- **ウェブサイト:** https://kvnkillian.github.io/
