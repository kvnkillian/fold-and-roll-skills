# Fold&Roll DM 스킬

> 이 문서는 기계 번역본입니다. 원어민 검토를 환영합니다.

던전스 & 드래곤즈를 운영하기 위한 무료 AI 에이전트 스킬 — Fold&Roll 제작팀 제공.

Claude Code, Codex, Cursor, 또는 Agent Skills 공개 표준을 읽는 모든 에이전트에 설치하면, 에이전트는 감에 의존해 D&D 조언을 즉흥적으로 늘어놓는 대신 DM처럼 준비하기 시작합니다. 줄거리가 아니라 상황, 사건이 아니라 결과를. 으스스함이 먼저, 웃음은 한 박자 늦게.

**모두를 테이블로.**

## 스킬

| 스킬 | 하는 일 |
|---|---|
| `encounter-builder` | 파티 레벨, 인원, 난이도에 맞춘 균형 잡힌 기억에 남는 5e 인카운터 — 지형, 전술, 반전 포함. |
| `npc-generator` | 버릇, 원하는 것, 비밀을 가진 NPC — 목소리, 갈고리, 파티가 무시했을 때 일어나는 일 포함. |
| `session-prep` | 한 페이지짜리 세션 준비: 상황, 3~5개의 노드, 장면의 시작, 진영의 움직임, 마무리할 클리프행어. |
| `one-shot-builder` | 3~4시간짜리 완전한 원샷: 갈고리, 세 개의 막, 인카운터, NPC, 결말. |
| `solo-adventure` | 한 명의 플레이어와 에이전트 DM을 위한 솔로 어드벤처 — 선택, 결과, 진짜 결말. |
| `campaign-arc` | 세 개의 막과 여섯 개의 비트로 이루어진 캠페인 아크 — 무엇이 일어나는지가 아니라 무엇이 변하는지로 정의. |
| `dice-roller` | 어떤 주사위든 굴립니다 — 유리함, 불리함, 치명타, 피해, 단체 굴림 — 합계만이 아니라 주사위를 보여줍니다. |

## 설치

### Claude Code

```sh
claude plugin install fold-and-roll-skills@kvnkillian
```

또는 개인 스킬 폴더에 스킬을 복사합니다.

```sh
git clone https://github.com/kvnkillian/fold-and-roll-skills.git
cp -r fold-and-roll-skills/skills/* ~/.claude/skills/
```

### Codex / Cursor / Copilot

```sh
npx skills@latest add kvnkillian/fold-and-roll-skills
```

또는 프로젝트의 `.agents/skills/` 폴더나 개인용 `~/.agents/skills/` 폴더에 스킬을 복사합니다.

### 기타 에이전트

`skills/<name>/` 폴더를 에이전트가 스킬을 읽는 위치에 복사합니다. 각 스킬은 하나의 `SKILL.md` 파일로 이루어져 있습니다. 빌드 단계도, 의존성도 없습니다. `scripts/roll.py`의 주사위 도우미는 Python 3만 있으면 됩니다.

## 사용법

에이전트에게 평범한 말로 요청하세요. 스킬 설명이 언제 작동해야 하는지 알려줍니다.

- "레벨 5 캐릭터 네 명을 위한 어려운 난이도의 인카운터를 만들어 줘. 물에 잠긴 신전이 배경이야."
- "NPC 하나 줘. 너무 많은 걸 아는 대장장이."
- "오늘 밤 세션을 준비해 줘. 지난번에 파티가 길드와 다리를 불태웠어."
- "유령 등대를 배경으로 한 원샷을 써 줘."
- "내 레벨 3 도적을 위한 솔로 어드벤처를 진행해 줘."
- "자기 이름을 잊어버린 도시에 대한 캠페인 아크를 계획해 줘."

에이전트는 정말 필요한 몇 가지 세부 사항 — 파티 레벨과 인원, 분위기, 세션 길이 — 만 물어본 뒤 바로 운영할 수 있는 결과물을 내놓습니다.

## Fold&Roll 방식

이 스킬들은 Fold&Roll이 만들어진 것과 같은 규칙을 따릅니다.

- **줄거리가 아니라 상황을 준비하세요.** 상황은 플레이어와 부딪혀도 살아남습니다. 줄거리는 플레이어가 계획에 없던 행동을 하는 순간 무너집니다.
- **플레이어는 공동 작가입니다.** 플레이어 캐릭터의 대사, 생각, 결정을 대신 서술하지 마세요. 선택은 언제나 플레이어의 것입니다.
- **으스스함이 먼저, 웃음은 한 박자 늦게.** 불안한 것 옆에 앉은 농담, 건조하고 긴장된 재치가 섞인 공포 — 노골적이거나 그 자체로 잔인한 묘사는 없습니다.
- **말이 없으면 SRD만 사용합니다.** 몬스터, 주문, 아이템은 SRD 5.1 / 5.2.1에서 가져옵니다. 홈브루는 홈브루라고 표시하고, 만들기 전에 에이전트가 먼저 물어봅니다.
- **안전이 먼저입니다.** 세션 제로, 라인 & 베일(Lines & Veils), X-카드(X-card)는 준비의 일부이지 나중에 덧붙이는 것이 아닙니다.
- **모두를 테이블로.** 모든 플레이어가 사용할 수 있는 콘텐츠를 유지합니다. 명확한 언어, 시각 정보에만 의존하지 않는 내용, 보거나 들어야만 이해되는 농담은 없습니다.
