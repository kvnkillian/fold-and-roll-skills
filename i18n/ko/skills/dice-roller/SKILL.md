# 주사위 굴리기

주사위를 굴리고, 주사위를 보여주고, 결과를 그대로 받아들이세요. 어느 방향으로든 속이지 마세요.

## 굴리기 전에 — 중요한 것부터 물어보세요

빠진 것만 물어보세요. 기본값은 대괄호 안에 있습니다.

1. **무엇을 굴릴지** — 표기법, 예: `2d6+3`, `d20`, `4d6` [물어보기 — 안전한 기본값 없음]
2. **유리함 / 불리함** — d20 판정의 경우 [사용자가 말하지 않는 한 어느 쪽도 아님]
3. **굴림의 목적** — 공격, 판정, 내성 굴림, 피해 [결과의 해석이 달라진다면 물어보고, 그렇지 않다면 굴리고 무엇이었는지 말하기]

사용자가 그냥 "굴려 줘"라고만 하면 표기법을 한 번 물어본 뒤 굴리세요.

## 규칙

- **합계만이 아니라 주사위를 보여주세요.** 항상 각 주사위를 먼저 보고한 뒤 합계를 말하세요: `2d6+3: [4, 2] + 3 = 9`. 주사위 없는 합계는 굴림이 아닙니다.
- **가능하면 스크립트를 사용하세요.** 저장소 루트에서 `python3 scripts/roll.py <notation>`을 실행하고(Python 3, 표준 라이브러리만 사용) 그 출력을 보고하세요. 스크립트를 사용할 수 없으면 정직하게 굴리고 스크립트 없이 굴렸다고 말하세요.
- **유리함과 불리함은 d20 두 개입니다.** 유리함: d20 두 개를 굴려 더 높은 것을 사용합니다. 불리함: d20 두 개를 굴려 더 낮은 것을 사용합니다. 두 주사위를 모두 보여주세요. 주사위 하나만 굴리고 유리함이라고 부르지 마세요.
- **공격에서 내추럴 20은 치명타(critical hit), 내추럴 1은 치명적 실패(critical miss)입니다.** 치명타 뒤의 피해 굴림에서는 피해 주사위를 두 번 굴리세요(수정치는 두 배로 하지 마세요). 일어나면 그렇게 말하세요 — "내추럴 20, 치명타" — 그런 뒤 피해를 굴리세요.
- **난이도(DC)나 목표는 주사위가 떨어지기 전, 또는 직후에 밝히세요** — 플레이어가 이미 결과를 바탕으로 다른 계획에 전념한 뒤에는 절대 밝히지 마세요.
- **굴림을 속이지 마세요.** 결과가 파티에게 나쁘든 몬스터에게 나쁘든 그대로 둡니다. 실패한 굴림은 상황을 바꿉니다. 이야기를 멈추게 하지 않습니다.
- **요청받지 않고 플레이어 캐릭터를 위해 굴리지 마세요.** 플레이어는 자신의 주사위를 직접 굴립니다. 에이전트는 몬스터, NPC, 그리고 세상을 위해 굴립니다 — 플레이어를 위해서는 플레이어가 요청할 때만 굴립니다.

## 표기법

| 표기법 | 의미 |
|---|---|
| `d20` | 20면체 주사위 하나 |
| `2d6+3` | 6면체 주사위 두 개, +3 |
| `4d6 drop lowest 1` | 6면체 주사위 네 개, 가장 낮은 것 하나 버리기(능력치) |
| `d20 advantage` | d20 두 개, 더 높은 것 사용 |
| `d20 disadvantage` | d20 두 개, 더 낮은 것 사용 |
| `8d6` | 6면체 주사위 여덟 개(예: 파이어볼) |
| `1d4+1` | 4면체 주사위 하나, +1 |

수정치는 주사위 뒤에 한 번만 더합니다 — 규칙이 그렇게 하라고 하지 않는 한 주사위마다 더하지 마세요.

## 출력 형식

```markdown
**굴림:** <무엇을 위한 굴림인지>
**주사위:** <표기법>: [<각 주사위>] <+/- 수정치> = <합계>
**결과:** <의미 — 명중 / 빗나감, 내성 성공 / 실패, 입힌 피해>
```

유리함 / 불리함의 경우:

```markdown
**굴림:** <무엇을 위한 굴림인지> — 유리함
**주사위:** d20: [14, 7] → 14 선택, + 5 = 19
**결과:** <의미>
```

## 단체 굴림

여러 생명체가 같은 것을 굴릴 때 — 예를 들어 고블린 무리가 내성 굴림을 할 때 — 생명체마다 한 번씩 굴리고 각 결과를 각각의 줄에 나열하세요. 사용자가 그렇게 해 달라고 하지 않는 한 한 번만 굴려서 전체 집단에 적용하지 마세요.

## Fold&Roll 목소리

주사위는 목소리가 평범하게 유지되는 유일한 곳입니다. 굴림 자체에는 꾸밈이 없습니다 — 드라마는 보고 방식이 아니라 결과에 있습니다. 주사위는 한 줄, 의미는 한 줄, 그리고 다시 게임으로 돌아가세요.
